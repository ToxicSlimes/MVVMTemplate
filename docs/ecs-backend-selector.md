# ECS Backend selector

`Tools/MVVM/ECS Backend/MORPEH` и `STATIC_ECS` переключают одновременно Standalone, Android и WebGL после подтверждения. `Validate` проверяет наличие ровно одного из двух разных символов в каждом target и одинаковый выбор между targets. Другие build target groups не изменяются. Команды не выполняются во время Play Mode или компиляции.

## Политика сохранения и восстановления

Переключатель меняет `MORPEH`, `STATIC_ECS` и, при необходимости, `MORPEH_DISABLE_AUTOINITIALIZATION`. При выборе StaticEcs отсутствующий флаг отключения автоматически добавляется вместе с маркером `MVVM_ECS_OWNS_MORPEH_DISABLE`. При возврате на Morpeh переключатель удаляет флаг только при наличии этого маркера. Если флаг существовал до выбора StaticEcs, он сохраняется. Остальные символы сохраняются; пустые элементы и разделители нормализуются.

Перед записью снимаются снимки всех трёх строк; каждое изменение проверяется повторным чтением. При исключении уже затронутые targets откатываются к снимку только если их текущее состояние совпадает с записанным переключателем. Если другой процесс изменил строку, она не перезаписывается; ошибка требует ручного исправления. Снимки хранятся только в памяти: аварийное завершение Unity или машины не позволяет автоматический откат. После аварии используйте Validate и вручную проверьте targets. Изменения, сделанные параллельно между проверкой и записью, API Unity атомарно защитить не позволяет; не редактируйте defines одновременно.

Повторный выбор backend не восстанавливает старые флаги: он только выбирает соответствующий backend и сохраняет текущие прочие defines. Selector не проверяет компиляцию, сборки player, наличие пакетов или фактический жизненный цикл ECS.

Чистую логику можно проверить командой `dotnet run --project Tests/EcsBackend~/EcsBackend.Tests.csproj`; это не заменяет тесты Unity Editor.
